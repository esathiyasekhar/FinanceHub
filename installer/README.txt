Finance Hub — Setup
===================

Install or upgrade:  double-click  Setup.cmd
  1. Program folder  (default C:\Program Files\Finance Hub)  — Windows asks once for permission.
  2. Data folder     (default D:\Finance Hub, or C:\Finance Hub Data without a D: drive) — your encrypted data,
                     logs and backups. Never removed by uninstalling.
  3. Optionally bring over the data of an older Finance Hub folder (the folder with users.json).
  4. Shortcuts (Start menu, Desktop), start with Windows, start now.
Then the Hub opens in your browser and a short setup asks for your name, user ID, password, mail and features.

Needs: Windows 10/11, Python 3.10 or newer (python.org — tick "Add python.exe to PATH"), internet the first time.

Uninstall: Settings > Apps > Finance Hub > Uninstall   (or  Setup.cmd /uninstall).  Your data folder is kept.

Optional single .exe installer: install Inno Setup 6 (free) and run build_exe.bat.
