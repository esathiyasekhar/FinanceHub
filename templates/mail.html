Setting up the Hub's mailbox (once)
  1. Create a new Gmail address only for the Hub — don't use your main mailbox.
  2. On that account turn on 2-Step Verification, then create an app password (Google Account › Security › App passwords). Gmail shows it once as 16 letters — paste it below. If Gmail asks, make sure IMAP is on (Gmail settings › Forwarding and POP/IMAP).
  3. In your own mailbox, add the Hub's address as a forwarding address (Gmail sends a code to the Hub's mailbox — open it there), then create a filter that forwards only statement mails, for example:
    from:({{ s.senders.split()|join(' OR ') }}) has:attachment
  4. Your own address goes into “My forwarding addresses” below only if you will also forward mails by hand.
