Setting up a mailbox for the Hub
Gmail
  1. Best: a new Gmail address only for the Hub.
  2. Turn on 2-Step Verification for it, then create an app password at myaccount.google.com/apppasswords — your normal Gmail password does not work here.
  3. Forward statement mails to it from your own mailbox with a filter, e.g. from:({{ s.senders.split()[:6]|join(' OR ') }} …) has:attachment
Outlook.com / Hotmail / Microsoft 365
  1. Outlook no longer accepts passwords from apps — the Hub signs in with Microsoft. It needs an application (client) ID, made once, free:
  2. portal.azure.com › App registrations › New registration — name Finance Hub, account types Accounts in any organizational directory and personal Microsoft accounts, no redirect › Register. (With only a personal Outlook account Microsoft first asks you to create a free Azure account — it may ask for a card to verify you; registering costs nothing.)
  3. Copy the Application (client) ID; then Authentication › Allow public client flows = Yes › Save.
  4. Add the mailbox below with that ID, then Sign in with Microsoft and type the code shown.
